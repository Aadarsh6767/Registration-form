# Registration Form

A responsive and interactive user registration form built using HTML, CSS, and JavaScript.

 Features

  Responsive Design: Styled to adapt cleanly across mobile, tablet, and desktop screens.
  Client-Side Validation: Form inputs are validated in real-time before submission using JavaScript.
  Modern UI: Clean layout and intuitive input states for user feedback.

 Built With

HTML5: Semantic markup structure (`index.html`).
CSS3: Custom styling and responsive layout (`register.css`).
JavaScript (ES6): Input validation logic and event handling (`register.js`).
